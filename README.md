# AdVantage Creator Hub

Create a mobile-first responsive web application called 'AdVantage:Project & Resource Discovery Engine'. Build a clean landing page with three distinct navigation views or user roles: 1) A 'Learn' feed that looks like Instagram Reels/TikTok for viewing short tech project videos, 2) A 'Creator Dashboard' for student developers to showcase work, and 3) A 'Content Editor Hub' where creators can browse project listings to make videos."
